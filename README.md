# 系统集成项目管理工程师（中级）备考学习工具

一个**零依赖、零构建**的纯前端备考学习工具，覆盖软考「系统集成项目管理工程师（中级）」核心考纲。数据保存在浏览器本地（localStorage），无需服务器即可运行。

## 功能

- **知识点梳理**：按模块分组的约 100 个考点卡（含挣值 / 三点估算 / EMV / 沟通渠道等公式与易混概念），支持单章展开 / 收起 / 切换。
- **章节练习**：按「章节 + 难度（易 / 中 / 难）+ 题型（单选 / 多选 / 判断）」三维筛选，提交即时判分并给出解析。
- **模拟试题**：3 套全真模拟卷（按考纲难度分布抽样），交卷出成绩与正确率。
- **错题回顾**：自动收集答错题，支持按章节筛选、标记已掌握、移除、一键重练。
- **学习进度跟踪**：已练题数、整体正确率、已掌握章节、待巩固错题、模拟均分、各章节进度条。

考纲覆盖：项目管理基础、立项管理、整体 / 范围 / 进度 / 成本 / 质量 / 资源 / 沟通 / 干系人 / 风险 / 采购管理、合同管理、变更与配置管理、信息安全 · 法律法规与标准规范。

## 本地运行

直接用浏览器打开 `index.html` 即可（双击或拖入浏览器）。

- 所有题目与知识点位于 `js/data.js`，可直接替换为官方教程例题与历年真题，逻辑无需改动。
- 进度、错题、模拟成绩保存在浏览器本地，清除浏览器数据会丢失。

## 目录结构

```
xiangmu-prep/
├── index.html          # 入口页面
├── css/styles.css      # 样式
├── js/data.js          # 考纲数据（章节 / 知识点 / 题库，含难度标签）
├── js/store.js         # 状态层（进度 / 错题 / 模拟 / 持久化）
└── js/app.js           # 界面渲染 + 通用答题引擎
```

## 部署到 GitHub Pages

本项目是纯静态站点，部署到 GitHub Pages 后可通过浏览器直接访问。

### 方式一：通过 git 推送（推荐）

1. 在 GitHub 新建仓库（如 `xiangmu-prep`）。
2. 本地初始化并提交：
   ```bash
   git init
   git add .
   git commit -m "feat: 系统集成项目管理工程师备考学习工具"
   ```
3. 关联远程并推送 `main` 分支：
   ```bash
   git remote add origin https://github.com/<你的用户名>/xiangmu-prep.git
   git branch -M main
   git push -u origin main
   ```
4. 在仓库 **Settings → Pages** 中，Source 选择 **Deploy from a branch**，Branch 选 **main**、目录选 **/ (root)**，保存。
5. 等待约 1 分钟，访问 `https://<你的用户名>.github.io/xiangmu-prep/` 即可运行。

### 方式二：GitHub Codespaces（在线开发 / 预览）

1. 仓库页面点击 **Code → Codespaces → Create codespace on main**。
2. 在 Codespace 终端运行 `python3 -m http.server 8000`（或任意静态服务器），点击 **Open in Browser / Ports** 转发端口即可在浏览器打开。

> 提示：若仓库设为 Private，Pages 也可启用（GitHub 全套餐支持），但访问需登录授权；公开仓库链接任何人可访问。
